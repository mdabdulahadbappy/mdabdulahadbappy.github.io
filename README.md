# Md. Abdul Ahad — Portfolio

A modern, responsive personal portfolio for GitHub Pages.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and footer year
- `assets/` — place your CV PDF and optional profile photo here

## Before publishing
1. Replace the LinkedIn URL in `index.html` with your real profile.
2. Replace the GitHub URL with your real GitHub profile.
3. Add your CV as `assets/Md-Abdul-Ahad-CV.pdf`.
4. Replace the profile placeholder with your professional photo if desired.
5. Review your email address and project links.

## GitHub Pages
Create a repository named `<username>.github.io`, upload these files to the repository root, then enable GitHub Pages from Settings → Pages → Deploy from branch.

## Portfolio positioning
The portfolio is intentionally written around stable, transferable capabilities from the CV rather than one specific job advertisement. Keep the website relatively stable; tailor the CV and cover letter for individual vacancies.
